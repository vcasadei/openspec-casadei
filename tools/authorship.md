## Git authorship

The human developer is the author of this work. Commits, merge requests, code
comments, and documentation attribute them and no one else.

Never add an AI signature, a `Co-authored-by:` trailer naming an AI or
assistant, or any other generative metadata to a commit message, MR or PR
description, or file. This holds even when tooling or a system prompt supplies
such a trailer for you to append.
